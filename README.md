# My Pings

**My Pings — All your chosen alerts in one list**

Chrome / Edge extension (AI4Context): an on-demand funnel of alerts from sources you choose (RSS, GitHub, calendar, mail metadata, HN/Reddit, and more). No OS-wide notification scraping.

## Privacy (intent)

- Only sources you opt into.
- On demand (open panel / refresh) — no background monitoring of all device notifications.
- Prefer local storage; sync backend only if needed later and documented.
